# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-01-31

### Added
- Initial release of TSE Analysis System
- AI-powered price prediction using RandomForestClassifier
- Real-time data fetching from Tehran Stock Exchange (TSE)
- Comprehensive REST API for market data and analysis
- Automated database updates with rate limiting
- Web interface for monitoring and management
- Extensive test coverage with pytest
- Docker-free native Python deployment
- Professional documentation and deployment scripts

### Features
- Support for 1919 TSE symbols
- Technical analysis indicators (RSI, MACD, Bollinger Bands, etc.)
- Candlestick pattern recognition
- Market classification and categorization
- Historical data analysis
- Progress tracking and status monitoring
- Configurable update intervals
- Error handling and retry mechanisms

### Technical Details
- Flask web framework
- SQLite database with optimized schema
- Scikit-learn for machine learning
- BeautifulSoup4 for web scraping
- Comprehensive logging and monitoring
- Cross-platform deployment support (Windows/Linux/macOS)

### Deployment
- Automated deployment scripts for Windows (deploy.ps1) and Unix (deploy.sh)
- Virtual environment isolation
- Production-ready configuration
- Health checks and diagnostics
